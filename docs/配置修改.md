# 配置修改

本工具所有可调参数都集中在 `config/config.json`（JSON 格式、UTF-8 编码）。
修改后保存，重启程序即生效。

首次使用运行 `--setup` 自动生成文件。个人配置不纳入版本管理；发布打包只生成空白账号。配置采用原子保存，JSON 格式、字段类型或非正整数的时间/次数会直接报错，避免使用空配置继续运行。

## 方式一：交互式初始化

运行以下命令，按提示逐项填写：

```bash
python src/main.py --setup
```

它会提示你输入学号、密码、WiFi 名称、接入选项，并自动写回配置文件。

## 方式二：手动编辑

用任意文本编辑器打开 `config/config.json`，修改后保存即可。字段说明如下：

### network（网络）

| 字段 | 类型 | 说明 | 默认值 |
| --- | --- | --- | --- |
| `ssid` | string | 校园网 WiFi 名称 | `JXUAS` |
| `ssid_backup` | string | 备用 WiFi（宿舍信号弱时用） | `JXUAS-2.4G` |
| `portal_url` | string | 认证门户地址 | `http://172.16.20.18/` |
| `self_service_url` | string | 自助服务平台（运营商绑定用） | `http://172.16.20.19:8080/selfservice/` |
| `test_url` | string | 判断是否联网的测试地址 | `https://www.baidu.com/` |
| `connect_timeout` | int | 每个 WiFi 等待实际连接的时间（秒） | `15` |
| `auth_timeout` | int | 提交认证后等待外网恢复的时间（秒） | `15` |

### account（账号）

| 字段 | 类型 | 说明 | 默认值 |
| --- | --- | --- | --- |
| `username` | string | 用户名（学号） | 空 |
| `password` | string | 密码 | 空 |
| `access_option` | string | 接入选项 | `校园网学生接入` |
| `broadband_account` | string | 运营商宽带账号（预留） | 空 |
| `broadband_password` | string | 运营商宽带密码（预留） | 空 |

### browser（浏览器）

| 字段 | 类型 | 说明 | 默认值 |
| --- | --- | --- | --- |
| `driver_path` | string | 手动指定 msedgedriver 路径，相对路径以程序基目录为准；无效路径会报错 | 空 |
| `headless` | bool | `true` 后台运行不弹窗 | `false` |
| `timeout` | int | 页面加载/元素定位超时（秒） | `30` |

### auto_login（自动认证）

| 字段 | 类型 | 说明 | 默认值 |
| --- | --- | --- | --- |
| `check_interval` | int | 常驻模式检测间隔（秒） | `30` |
| `max_retry` | int | 认证失败重试次数 | `3` |
| `retry_delay` | int | 同一轮两次认证尝试之间的等待时间（秒） | `5` |
| `max_backoff` | int | 连续故障时的重试等待上限（秒），实际不低于检测间隔 | `300` |

### logging（日志）

| 字段 | 类型 | 说明 | 默认值 |
| --- | --- | --- | --- |
| `level` | string | 日志级别：DEBUG/INFO/WARNING/ERROR | `INFO` |
| `log_dir` | string | 日志目录 | `logs` |

## 常见修改示例

**1. 修改账号密码**

```json
"account": {
  "username": "2026123456",
  "password": "你的新密码",
  "access_option": "校园网学生接入"
}
```

**2. 更换 WiFi 名称（例如只连 2.4G）**

```json
"network": {
  "ssid": "JXUAS-2.4G",
  "ssid_backup": "JXUAS"
}
```

**3. 后台静默运行（不弹浏览器）**

```json
"browser": {
  "headless": true
}
```

**4. 调慢检测频率以省资源**

```json
"auto_login": {
  "check_interval": 120
}
```

> 配置文件使用 UTF-8 编码，中文内容请勿用 Windows 记事本「另存为 ANSI」保存，
> 否则可能出现乱码。推荐使用 VS Code、Notepad++ 等编辑器。

## 自定义配置和驱动准备

```bat
python src/main.py --config "my settings.json" --setup
python src/main.py --config "my settings.json" --prepare-driver
python src/main.py --config "my settings.json" --headless --install-autostart
```

`--config` 的相对路径以执行命令时的目录为准；注册自启动会保存为绝对路径。`--prepare-driver` 必须在联网时执行，不会访问校园网门户或提交账号密码。密码前后空格会原样保存；个人配置请只保留在本机。
