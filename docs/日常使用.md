# 日常使用

## 正常使用流程

1. 电脑开机后，工具（若已安装自启动）会在后台常驻运行。
2. 到达宿舍/校园后，电脑自动连接 `JXUAS`（需已保存过密码）。
3. 工具检测到未认证，自动拉起 Edge 完成登录。
4. 认证成功后即可正常上网；掉线时会自动重连、自动重新认证。

> 运行期间建议让控制台窗口保持打开（或最小化），关闭窗口即退出程序。

## 常用命令速查

```bash
python src/main.py                    # 常驻运行（默认）
python src/main.py --once             # 只认证一次后退出
python src/main.py --setup            # 交互式配置
python src/main.py --headless         # 不弹 Edge 窗口，控制台仍保持打开
python src/main.py --prepare-driver   # 联网时提前准备驱动
python src/main.py --install-autostart   # 开机自启动
python src/main.py --uninstall-autostart # 取消自启动
```

## 常见问题排查

### 1. 首次登录提示「修改密码」

系统强制首次改密，脚本无法代劳。请手动登录门户完成改密，之后交给工具即可。

工具识别到明确的改密或密码错误提示后会停止自动重试。完成手动处理、修正配置后请重新启动程序。

### 2. 提示「账号不存在 / 密码异常」

- 确认是否已完成缴费且超过 24 小时；
- 确认用户名是学号、密码无误；
- 仍无法解决，加 QQ 群 `869659135` / `1062385993` 咨询管理员。

### 3. 无法自动连 WiFi

- 请先手动连接一次 `JXUAS` 并勾选「自动连接」，Windows 才能自动重连；
- 网线用户无需 WiFi，工具会直接对有线网进行认证。

### 4. 提示「无法访问认证门户」

说明当前不在校园网环境（如在家/用手机热点），工具会自动跳过，回到校园后恢复。

### 5. 首次运行下载驱动失败

连接手机热点或手动登录一次后，执行 `python src/main.py --prepare-driver`（exe 用户使用 `dist\jxuas-autologin.exe --prepare-driver`）。仅启动常驻程序不会预下载驱动。Edge 更新后如出现驱动不匹配，也可重新执行此命令。

已有驱动时可填写 `browser.driver_path`；相对路径以程序基目录为准。路径无效时会明确报错，不会偷偷改为下载。

### 7. 配置文件报错或单次运行失败

配置格式、类型或数值错误会明确提示，请修正后重试；旧版本配置缺少新增字段时会自动使用默认值。运行 `--once` 后可查看退出码：0 成功、1 故障、2 配置错误、3 门户不可达、4 需要人工处理。临时故障会按配置重试并逐步延长等待时间。

### 6. 门户页面改版导致元素定位失败

门户结构变化可能使自动填写失败。可：

- 查看日志 `logs/autologin.log` 确认卡在哪一步；
- 在 `src/authenticator.py` 顶部的 `*_SELECTORS` 常量中补充新的选择器；
- 临时手动登录，并向维护者反馈。

## 运营商宽带绑定（可选）

若已办理个人校园宽带，可绑定运营商以优化网络：

1. 登录自助服务平台 `http://172.16.20.19:8080/selfservice/`（首次登录需绑定邮箱）；
2. 进入【我的运营商】，填写运营商账号（格式 `手机号@lan`）与密码（短信下发的 6 位数字）；
3. 确认绑定。

> 该绑定是一次性手动操作，本工具负责的是校园网认证本身；绑定后自动认证不受影响。
