# 环境准备

在使用本工具之前，请先确认以下环境与账号条件，确保一次跑通。

## 一、系统与软件要求

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| 操作系统 | Windows 10 / 11 | 本工具依赖 `netsh` 与 Edge，仅支持 Windows |
| 浏览器 | Microsoft Edge | Windows 自带；用于完成网页认证交互 |
| 无线网卡 | 支持 WLAN | 仅「自动连 WiFi」功能需要，网线用户可忽略 |
| Python（可选） | 3.11+，推荐 3.11 或 3.12 | 仅「源码运行 / 二次开发」需要；纯 exe 用户无需安装 |

## 二、账号准备

1. **已完成缴费**：通过「江西应用科技学院」公众号底部菜单【微服务】→【缴费通道】，
   选择「智慧校园网络费」并完成缴费。
2. **账号已同步**：缴费后系统约 **24 小时内**自动同步账号（缴费完成不等于立即生效）。
3. **账号信息**：
   - 用户名：**学号**
   - 初始密码：**身份证后 6 位**
4. **首次登录改密**：首次登录系统会**强制要求修改密码**，请牢记修改后的新密码。

> 若提示「账号不存在 / 密码异常」，请加入网络反馈 QQ 群 `869659135`、`1062385993`
> 联系管理员处理。

## 三、认证流程回顾（对照公众号教程）

本工具完整还原了校方公众号的电脑端登录流程：

1. 电脑连接 WiFi `JXUAS`（或网线直连宿舍光猫/墙面网络面板）。
2. 打开浏览器访问认证门户 `http://172.16.20.18/`。
3. 填写 **学号**、**密码**，接入选项选择 **校园网学生接入**，点击 **连接**。
4. 认证成功后即可上网。

本工具就是把第 2~3 步交给 Edge 自动完成：自动打开门户、自动填写、自动选择接入
选项、自动点击登录。

## 四、工具运行原理

```
循环检测
   │
   ├─ 已联网/已认证 ────────────► 等待下次检测
   │
   └─ 未认证
         │
         ├─ 尝试连接 JXUAS WiFi
         ├─ 探测门户 172.16.20.18 是否可达
         │        └─ 不可达：说明不在校园网，跳过
         └─ 可达：启动 Edge 自动填写并登录
                    └─ 再次探测外网，确认结果
```

> 为什么用浏览器自动化而不是直接发请求？因为认证门户的密码加密、会话校验由页面
> 自身的 JavaScript 完成，直接驱动浏览器可天然复用这些逻辑，对门户改版也更稳健。
