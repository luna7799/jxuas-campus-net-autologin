# 安装部署

本文介绍两种使用方式：**源码运行**（适合二次开发）与 **打包为 exe**（适合日常使用）。

## 方式一：源码运行

### 1. 安装 Python

前往 <https://www.python.org/downloads/> 下载 Python 3.11+（推荐 3.11 或 3.12），安装时务必勾选
**Add Python to PATH**。

安装完成后验证：

```bash
python --version
```

### 2. 获取代码并安装依赖

```bash
git clone https://github.com/luna7799/jxuas-campus-net-autologin.git
cd jxuas-campus-net-autologin
pip install -r requirements.txt
```

> 建议使用虚拟环境隔离依赖：
> ```bash
> python -m venv .venv
> .venv\Scripts\activate
> pip install -r requirements.txt
> ```

### 3. 填写配置并运行

先生成个人配置，再在可联网环境中准备驱动：

```bash
python src/main.py --setup
python src/main.py --prepare-driver
```

配置保存在 `config/config.json`，该文件不会进入版本管理。回到校园网后运行：

```bash
python src/main.py
```

也可以双击 `run.bat` 直接运行。

## 方式二：打包为独立 .exe

### 1. 一键打包

双击仓库根目录的 `build.bat`。脚本会自动：

1. 创建虚拟环境 `.venv`；
2. 安装依赖并执行回归测试；
3. 使用 PyInstaller 打包为**单文件** `jxuas-autologin.exe`，包含 Selenium Manager；
4. 生成空账号配置到 `dist/config/`，不读取本机个人账号。

任一步失败都会停止。再次打包会重置发布目录的配置，请先备份其中需要保留的个人设置。自动化环境可运行 `build.bat --no-pause`。

完成后得到：

```
dist/
├── jxuas-autologin.exe      # 双击即可运行
└── config/
    ├── config.json          # 实际生效的配置
    └── config.example.json  # 配置示例
```

### 2. 运行

先在命令行执行：

```bat
dist\jxuas-autologin.exe --setup
dist\jxuas-autologin.exe --prepare-driver
```

准备驱动时需联网，并且电脑已安装 Microsoft Edge。之后双击 exe 即可使用；Edge 升级后如出现驱动不匹配，请联网再次执行 `--prepare-driver`。也可设置 `browser.driver_path` 使用预先下载的驱动。

> 也可在命令行手动打包：
> ```bash
> python -m PyInstaller --onefile --name jxuas-autologin --console --paths src --collect-all selenium src/main.py
> python scripts/prepare_release.py dist
> python scripts/check_package.py dist
> ```

## 开机自启动

- **exe 用户**：双击 `scripts/install_autostart.bat`；
- **源码用户**：`python src/main.py --install-autostart`。

取消自启动：双击 `scripts/uninstall_autostart.bat` 或
`python src/main.py --uninstall-autostart`。

> 自启动写入的是**当前用户**的注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，
> 无需管理员权限，也不会影响其他程序。

## 首次运行注意事项

1. **先手动登录一次**：首次登录系统会强制改密，请先在浏览器手动完成改密。
2. **先连过一次 WiFi**：Windows 只能自动连接「已保存过密码」的网络，请先手动连一次
   `JXUAS` 并勾选「自动连接」。
3. **联网准备驱动**：连接手机热点或手动登录一次后，执行 `--prepare-driver`；仅启动常驻模式不会提前下载 WebDriver。

自启动支持保留自定义配置和无头模式：

```bat
python src/main.py --config "C:\JXUAS\settings.json" --headless --install-autostart
```
