# 安装部署

本文介绍两种使用方式：**源码运行**（适合二次开发）与 **打包为 exe**（适合日常使用）。

## 方式一：源码运行

### 1. 安装 Python

前往 <https://www.python.org/downloads/> 下载 Python 3.8+，安装时务必勾选
**Add Python to PATH**。

安装完成后验证：

```bash
python --version
```

### 2. 获取代码并安装依赖

```bash
git clone https://github.com/<你的用户名>/jxuas-campus-net-autologin.git
cd jxuas-campus-net-autologin
pip install -r requirements.txt
```

> 建议使用虚拟环境隔离依赖：
> ```bash
> python -m venv .venv
> .venv\Scripts\activate
> pip install -r requirements.txt
> ```

### 3. 填写配置并运行

编辑 `config/config.json`，填入学号与密码，然后：

```bash
python src/main.py
```

也可以双击 `run.bat` 直接运行。

## 方式二：打包为独立 .exe

### 1. 一键打包

双击仓库根目录的 `build.bat`。脚本会自动：

1. 创建虚拟环境 `.venv`；
2. 安装 `selenium`、`requests`、`pyinstaller`；
3. 使用 PyInstaller 打包为**单文件** `jxuas-autologin.exe`；
4. 把配置文件复制到 `dist/config/` 下。

完成后得到：

```
dist/
├── jxuas-autologin.exe      # 双击即可运行
└── config/
    ├── config.json          # 实际生效的配置
    └── config.example.json  # 配置示例
```

### 2. 运行

双击 `dist/jxuas-autologin.exe` 即可。首次运行会自动下载与 Edge 版本匹配的
`msedgedriver`（需联网一次），之后即可离线使用。

> 也可在命令行手动打包：
> ```bash
> pyinstaller --onefile --name jxuas-autologin --console src/main.py
> ```

## 开机自启动

- **exe 用户**：双击 `scripts/install_autostart.bat`；
- **源码用户**：`python src/main.py --install-autostart`。

取消自启动：双击 `scripts/uninstall_autostart.bat` 或
`python src/main.py --uninstall-autostart`。

> 自启动写入的是**当前用户**的注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，
> 无需管理员权限，也不会影响其他程序。

## 首次运行注意事项

1. **先手动登录一次**：首次登录系统会强制改密，请先在浏览器手动完成改密。
2. **先连过一次 WiFi**：Windows 只能自动连接「已保存过密码」的网络，请先手动连一次
   `JXUAS` 并勾选「自动连接」。
3. **保证首次运行可联网**：Selenium 首次需下载 WebDriver，请确保当时机器可上网
   （如用手机热点，或先手动登录一次再运行）。
